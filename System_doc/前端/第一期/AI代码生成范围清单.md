# AI 代码生成范围清单 — Profile 走廊（第一期）

## 功能点（必须）

1. 全屏 Three.js 走廊，4 对门，天花中线暖灯。
2. 点击中轴文字/地面中带，相机缓慢前进到下一对门。
3. 点门：先转身，再点则铰链开门，然后进入 `/room/:doorId`。
4. HUD：`Profile` + 英文前进提示；不要中轴圆圈。
5. 房间数据来自静态 `rooms.json`。

## 验收标准

- 浏览器打开 `/`，第一人称暗走廊，灯在天花板中间一排。
- 前进 3 次后停在第 4 对门（`6`/`7`），再点中轴不往前。
- 点左门相机左转，再点门打开并进入 `/room/0`（示例）；右门同理。
- 网络面板无 API 调用。
- 包内无 cannon / rapier / ammo 等物理库。

## AI 可生成

- `Code/` 下 Vite React 工程、走廊场景组件、zustand、React Router、Tailwind HUD。
- 程序化几何（墙、地、门、灯）+ 简单木纹贴图或程序化材质。
- 房间页路由壳（室内细节以 door_Page 清单为准）。

## AI 禁止生成

- Express / SQLite / JWT / 任何后端服务。
- 物理：重力、碰撞网格、刚体、角色控制器（胶囊体碰撞）。
- 方案 B 展示图里的地面发光圆圈、准星。
- 把灯装在门楣与侧墙之间（已改为天花中线）。
- 门牌写死在贴图里导致无法改 `label`。
- 房间内桌/画/黑板的点击逻辑（第一期只摆放，见 door_Page）。
