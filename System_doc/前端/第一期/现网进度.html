2. 现网吊灯（前端占位，不是 GLB）

代码：Code/Module/Main/scene/CeilingLights.jsx。气质对齐 scheme-a-css3d-profile.png，不是半透明羊皮灯笼。

零件现网
罩浅宽截锥，口朝 −Y。外深色哑光，内暖色。口沿金属环。顶盖密封。
灯泡偏大梨形玻璃 + 灯丝环 + 两根支架 + 黄铜螺口 + 光晕。在腔内，从开口能看见。
吊线天花圆形灯座 + 可见吊线（半径约 11mm，颜色比天花亮）+ 罩顶铜箍。
主光朝下 SpotLight，angle≈1.18，打地板和墙裙。近处 4 盏（z ≤ 10.25）开阴影。
辅光罩内短距点光（只亮网膜/内壁）。灯座附近一盏点光，给天花哑光微亮，不制造地板那种拉丝反光。
场景光CorridorScene.jsx：暖环境光 + 半球光（ground 色照天花）+ 暖色 PMREM 环境贴图（给木头/铜反光）。

罩外侧有 8 条装饰楞条（从下往上看像 5～6 条黑线）。参考图里没有，是试细节时加的。下轮默认应删掉，除非产品明确要工业辐条。

表面要的效果现网材质要点

墙裙 / 门 / 铜 边棱有高光，不要镜面 中等 roughness；铜 metalness 0.9
