# UI 设计规范 — 房间页

目标图：[room-interior-v1.png](room-interior-v1.png)

## 气质

暗木房间，刚通电：灯在抖，家具从暗里显出来。稳定后仍偏暗、暖。

## 道具

| 道具 | 外观 | 第一期 |
| --- | --- | --- |
| 桌 | 实心厚木桌，无桌布 | 只看 |
| 凳 | 实心木凳 2～3 张 | 只看 |
| 画（左） | 画芯 **纯白**；框要精美（雕花/金或深木） | 只看 |
| 黑板（右） | 板面 **空白近白**；框简单深色；无粉笔字、无粉笔槽交互 | 只看 |

## HUD

- 左上：`Profile`，可加当前门 `label`。
- 返回：小字 `Back` 回 `/`。
- 不要教程弹窗；入场 10s 内不要大块 UI 挡住闪灯。

## 禁止

- 现代办公室白板风格（除非框仍是木/暗色）。
- 画芯画上风景或人物（第一期必须空白，留给以后交互）。
- 黑板写欢迎语。
