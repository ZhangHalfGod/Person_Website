# 入场交互时序

进入 `/room/:doorId` 后自动播放，不需要玩家再点一次才开始。

```
t = 0s
  房间几乎全暗；入场门关闭（或仅一条缝）
  桌 / 凳 / 画 / 黑板 已在场景中，但因无光几乎看不见

t = 0 ～ 2.5s
  门绕铰链缓缓打开（easeOut）
  开始有灯，但不稳

t = 0 ～ 10s  （与开门可重叠）
  每盏室内暖灯强度 = 目标亮度 * flicker(t)
  flicker：高频随机闪，包络从大到小
  约 10s 时 flicker ≈ 1，不再跳变
  此期间桌凳画黑板随光照逐渐被看清

t ≥ 10s
  灯光稳定
  玩家可看、可返回走廊
  道具仍无交互
```

## 闪烁（实现要点）

- 用 `useFrame` 改 `PointLight.intensity`，不要靠 CSS。
- 建议：`intensity = base * (1 - envelope * noise)`，`envelope` 从 0.8 降到 0（10s）。
- `base` 从暗抬到正常室内暖光。
- 可 2～3 盏灯、相位错开，更像电路不稳，不要频闪到癫痫（避免纯 50Hz 硬闪）。

## 门

- 与走廊相同：绕铰链转，不要绕中心。
- 速度慢于走廊那一下「推门」，这里是入场仪式（2～3s）。
