# 相机状态机 — 走廊

所有位移/旋转用 **相机动画**（lerp / 平滑 damp），不用物理速度。

```
LOOK_FORWARD
  中轴点击 且 stopIndex < 3  → WALKING_FORWARD
  中轴点击 且 stopIndex = 3  → 仍为 LOOK_FORWARD（提示 End of the corridor）
  点击当前停驻点左/右门     → TURNING_TO_DOOR
  后退（可选）且 stopIndex > 0 → WALKING_BACK

WALKING_FORWARD
  相机 position.z 插值到下一停驻点
  完成 → stopIndex += 1，LOOK_FORWARD

WALKING_BACK
  相机 position.z 插值到上一停驻点
  完成 → stopIndex -= 1，LOOK_FORWARD

TURNING_TO_DOOR
  相机 yaw 转向目标门中心
  完成 → FACING_DOOR（记录 facingDoorId）

FACING_DOOR
  再点同一扇门 → DOOR_OPENING
  点另一扇门   → TURNING_TO_DOOR（新目标）
  点中轴       → TURNING_BACK_FORWARD

TURNING_BACK_FORWARD
  yaw 回到 0（朝灭点）
  完成 → LOOK_FORWARD，facingDoorId = null

DOOR_OPENING
  该门绕铰链打开（左门铰链在门的外侧/靠墙边，向走廊内或按常见单开门外旋，保持左右对称）
  完成 → 路由 /room/:doorId
```

## 时长（建议）

| 动画 | 时长 |
| --- | --- |
| 前进 / 后退 | 0.8～1.2s |
| 转身 / 转回 | 0.6～0.9s |
| 开门 | 1.2～2.0s |

动画进行中忽略新的场景点击（防连点打乱状态）。

## 铰链

门 mesh 不要绕几何中心转。把旋转原点放到铰链边：

- `side: "left"`：铰链在门的 -X 边（靠左墙）。
- `side: "right"`：铰链在门的 +X 边（靠右墙）。
