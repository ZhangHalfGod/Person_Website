# Profile 走廊：视觉与交互需求（已锁定）

页面英文名：**Profile**。门牌 `0`～`7` 仅为占位，数据层用 `id` + `label`，以后可改成中文、英文或数字。

## 一、视觉（走廊）

1. 进入 `/` 即是第一人称走廊，通道向前延伸，近大远小，灭点在画面中心。
2. 整体 **暗黑**。暖灯挂在 **天花板正中一排**（走廊中线），照亮：墙下半截、地面、木门；墙上半截逐渐变暗。地板可有轻微灯塘反光；天花与上门墙是暗色微亮、哑光，不是纯黑，也不是地板那种拉丝反光。现网进度见 [../../前端/第一期/现网进度.html](../../前端/第一期/现网进度.html)。
3. 左右成对木门，共 **4 对**。当前停驻点一对最大，更远处还能看到下一对。
4. HUD：左上 **Profile**；中轴附近 **文字** 提示前进（如 `Click the corridor to walk forward`）。**不要**地面发光圆圈或准星。

参考图：[Start/profile-corridor-v1.png](Start/profile-corridor-v1.png)

## 二、交互（走廊，第一期必须）

| 动作 | 结果 |
| --- | --- |
| 点击走廊中轴（文字热区 / 地面中带） | 相机 **缓慢前移** 到下一对门正前 |
| `stop = 0` | 左右门 `0` / `1` |
| `stop = 1` | `2` / `3` |
| `stop = 2` | `4` / `5` |
| `stop = 3` | `6` / `7`（走廊尽头，中轴点击不再前进） |
| 第一次点击某扇门 | 相机从朝前 **缓缓转向** 该门 |
| 面向该门后再点一次 | 门 **绕铰链打开**，然后进入 `/room/:id` |
| 面向门时点中轴 | 相机转回朝前 |
| 后退 | 建议做：`stop > 0` 时回到上一对；`stop = 0` 停止 |

## 三、停驻点约定

```
stopIndex = 0, 1, 2, 3
leftDoor  = rooms[stopIndex * 2]       // 0, 2, 4, 6
rightDoor = rooms[stopIndex * 2 + 1]   // 1, 3, 5, 7
```
