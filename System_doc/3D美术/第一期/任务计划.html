做不做

对照 demo 图必须做的三条

这三条在图上很明显，不再写成「可选」。形体对不上 PNG，贴图再细也无效。

条Demo 图本期怎么做
1. 墙裙凹板 下半墙是一格格凹陷的矩形木板，有框、有进深，不是平贴一张木纹。 必做。 用模型或法线做出矩形凹板（门与门之间的节奏对齐参考图）。不要只刷平铺贴图。
2. 完整门套 近处门有框、楣、套，看起来是嵌进墙里的门，不是一块薄板贴在墙上。 必做。 门扇 + 左右竖框 + 上门楣（可与墙裙一体）。现有前端只有一条细楣，本期资产要补全门套。
3. 地板纵向木纹 木板沿走廊向灭点铺，灯斑顺着条纹拉长。 必做。 木纹 / UV 主方向沿 +Z，不要横铺。roughness 中低，能出软反光灯塘。

逐步任务

#任务输出
1.1在 Blender 按上表搭走廊白模，对着 PNG：先做出墙裙凹板和门套形体（可与前端尺寸对齐，不必一次做到最终面数）。工作 .blend
1.2地板：深色实木、可平铺、roughness 中低（要有灯斑）。木纹沿走廊 +Z 纵向铺，不要横铺。2K 起。见下方「前端当前锁定」
1.3墙裙：略亮于地板的木头；必做矩形凹陷木板（模型或法线），对齐参考图的分格。源可 PNG；网页 wainscot_*.jpg 及凹板模型/法线
1.4门：深色实木扇 + 完整门套（左右框、上门楣），有厚度与分缝。门牌不画进贴图。瘦 corridor_door.glb（含门套，不内嵌贴图）
1.5黄铜：把手 + 门牌框。metalness 高、roughness 偏低。brass_*.jpg（512，网页用；不必 2K PNG）
1.6吊灯 GLB（可后做）：口朝下、顶密封、腔内灯泡位、天花灯座 + 可见吊线。对齐 scheme-A 浅盘罩，不要外侧辐条楞。前端占位已在 CeilingLights.jsx，不必先开 Blender。ceiling_pendant.glb
1.7交 TA 过单位、铰链、体积；再交前端挂到 MeshStandardMaterial。见落盘路径
