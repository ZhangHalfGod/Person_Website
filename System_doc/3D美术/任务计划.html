工具与输出格式

制作可用 PNG 或带图的预览 GLB。给前端必须拆图、压 JPG、再导不带贴图的瘦 GLB。完整步骤见 材质交付操作.md。Houdini / Unity 不是这条链上的下一步，见 工具边界与后续计划。

工作工具输出
可平铺的木头 / 墙 / 黄铜（制作） Substance Painter 或 Poly Haven 纹理套件 源：PNG。网页：*_albedo.jpg / *_roughness.jpg / *_normal.jpg
有造型的灯、门扇、线脚 Blender 建模 + UV 网页：瘦 .glb（米制、Y-up，不要内嵌贴图）。JPG 由前端共用。
灯塘、门上高光、墙裙明暗 Three.js 实时灯 + MeshStandardMaterial 不另导烘焙贴图。不是 Houdini 灯光，也不是 Unity lightmap。
以后 破坏 / 烟尘体积 Houdini 模拟后烘焙缓存 仅当产品要崩塌、碎玻璃等镜头。不用于把门模再精修一遍。
以后 独立 3D 客户端 Unity 6 或 Unreal（禁止 Unity 5） 仅当改成可下载展馆。不与现网 Canvas 混装。
