## 1. 目标

在 `/room/0` 实现**精装天花板**：

1. **十字梁保留**；梁间四格用 **填心板填满**，顶面高度与梁 **齐平**（不是大挖空只剩槽）。
2. 桌区对应格内嵌 **约 1～2 条窄长灯槽**（「晴天灯」），有挡板/口沿。
3. 仰视灯槽内部呈现 **室外晴天感**（淡蓝天空 + 软云/柔渐变），**不是**过曝白光板。
4. 光从槽口 **向下主照**，服务室内桌面/地板；与暖灯并存时色温可略偏冷天光口。
5. 弱化或移除锥形吊灯存在感。

---

## 2. 视觉规格（验收口径）

| 项 | 要求 |
|----|------|
| 填心 | 四格填实，仰视见板面而非大空腔 |
| 槽形 | 窄长嵌在填心板内；挡板/收边可读 |
| 晴天感 | 淡蓝 + 软云或柔渐变；对比度低；禁止 HDR 死白过曝 |
| 数量 | 优先约 2 条主槽；忌满天花灯海 |
| 稳定态 | 与 lightMap **防双计**；不加回冷灰 hemi/dir |

---

## 3. 推荐实现路径

### 3.1 几何（Blender）— C1b

- `room_phase2.blend`：保留梁格；四格 `CofferFill_*`；桌区窄槽复用 `CofferSlotPanelEmit_*` 命名。
- 导出 `ceiling_coffers.glb`；材质名对齐 `useRoomMaterials` / `RoomInterior.cofferMaterial`。

### 3.2 材质「晴天」— C2（可复用）

- Emit：自发光 + `sky_slot_emit.jpg`；强度保守。
- 挡板：暗色收边。

### 3.3 局部重烘 — C3b

- C1b 后重烤天花 receivers（Fill/Beam/Baffle/Rim）；Emit 不吃 LM。
- 禁止无差别全家具重烤；地板视需要。

### 3.4 网页

- GLB / LM `?v=` cache bust；验收 `/room/0` 稳定态。

### 实现倾向（与 C4 光参衔接）

1. 罩体优先用网页 MeshPhysicalMaterial：**transmission + roughness** 做半透明/磨砂玻璃罩，内层继续淡蓝天空 Emit（可叠 Clarens Midday 弱采样）。

3. 外观目标：半透明玻璃罩晴空灯，**不是**四个黑色柱形。
