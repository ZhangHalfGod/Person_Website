3. 共用交互（三方案相同）

stopIndex = 0 时左右为门 0 / 1；点击走廊中轴后 stopIndex = 1，左右为门 2 / 3。label 只是展示文案。

leftDoor  = rooms[stopIndex * 2]
rightDoor = rooms[stopIndex * 2 + 1]
click corridor center → stopIndex += 1 → 镜头到下一对门正前
click a door         → 后期进入该房间（本期可先高亮）
back                 → stopIndex -= 1（到 0 停止）
