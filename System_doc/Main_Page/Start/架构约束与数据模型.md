## 坐标（约定）

- 走廊沿 **+Z** 向灭点延伸；相机在 Z=0 附近朝向 +Z。
- X：左负右正。左门在 -X，右门在 +X。
- Y：上正。灯在天花中线 `x = 0`，`y = 天花略下`。
- 每个停驻点间距相等（如 6～8 个单位），共 4 个停驻点。

## 目录（写入 `Code/Module`）

工程根在 `Code/`（`package.json`、`vite.config.js`）。业务在 `Code/Module/`：

```
Code/
  package.json
  index.html                          title: Profile
  Module/app/main.jsx
  Module/app/App.jsx                  BrowserRouter
  Module/Main/                        走廊（本文档）
    pages/ProfilePage.jsx
    scene/Corridor.jsx DoorPair.jsx CeilingLights.jsx cameraStops.js
    store/corridorStore.js
    overlay/ProfileHud.jsx
    data/rooms.json
    extensions/physics/               多期：重力碰撞刚体（一期空）
    extensions/backend/               多期：Express（一期空）
  Module/door/                        房间（见 door_Page）
  Module/Other/                       以后新模块
  public/textures/Main/
  public/textures/door/
```

别名：`@main` → `Module/Main`，`@door` → `Module/door`，`@app` → `Module/app`。

## 点击拾取

- 地面中带 mesh（或不可见 hitbox）→ 前进 / 在面向门时转回朝前。
- 门 mesh → 转身或开门。
- HUD 文字可 `pointer-events` 转发到同一前进动作。
- 使用 R3F `onClick` / Three Raycaster，不要用 DOM 假 3D。

## 开门后

`navigate(`/room/${doorId}`)`。房间场景 **另页另 Canvas**（第一期允许；不要在第一期做无缝走进同一场景，以免和物理扩展搅在一起）。
