# 房间页 — 可执行文档

> 在走廊批次 3（开门并 `navigate`）之后执行。8 个门同一套室内，不要复制 8 份场景文件。  
> 目标图：[room-interior-v1.png](room-interior-v1.png)

**入口**：`/room/:doorId`，`doorId` 为 `0`～`7`。非法 id 回到 `/`。

## 批次 R2：入场交互（必须）

| 步骤 | 操作 | 状态 |
| --- | --- | --- |
| R2.1 | 进入页面后 **门缓缓打开**（绕铰链，约 2～3s） | ✅ |
| R2.2 | 开门同时或紧接着：室内灯 **闪烁**，约 **10 秒** 内振幅变小、平均亮度升高，最后稳定 | ✅ |
| R2.3 | 闪烁过程中桌、凳、画、黑板从暗处显露（淡入或随灯光可见即可） | ✅ |
| R2.4 | 10 秒后灯光稳定，场景静止；仍不可点道具 | ✅ |

时序细节见 [入场交互时序.md](入场交互时序.md)。
