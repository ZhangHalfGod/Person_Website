天花吊灯 / 物理交互与阴影问题

记录日：2026-09-08。第一期走廊灯当前实现与真实「伞罩 / 扇形灯罩」不符：口朝上、灯泡在罩外、灯光不经过半透明网膜。 本文只分析，不改代码。对照图 profile-corridor-v1.png。

1. 正确的物理世界（要的效果）

一盏旅馆走廊吊灯：不透明或半透明的扇形 / 锥形罩，大口朝下，顶部密封，灯泡藏在罩腔内。

路径物理过程画面上应看到
直射（开口向下） 光线几乎不受挡，按距离平方衰减打到地板和墙裙。 灯下地板最亮；门和墙下半受光。这是主灯塘。
侧向透过网膜 罩壁是半透明 3D 网格（羊皮 / 布 / 磨砂），吸收 + 散射一部分光。 墙壁越往上越暗，是被罩挡住后的漏光，不是第二盏灯。
向上 罩顶密封，没有开口。只有极弱的散射，几乎到不了天花。 天花和上门墙接近黑。不应出现灯罩上方一圈亮斑。

图 1 · 侧视剖面。亮暗梯度来自罩的遮挡，不是单纯把 PointLight 调暗。

2. 当前前端实际在做什么

代码：Code/Module/Main/scene/CeilingLights.jsx。灯组在 y = HEIGHT - 0.42（约 3.13 m），沿走廊 +Z。

零件代码Three.js 含义
灯罩 coneGeometry(0.16, 0.2) + rotation={[Math.PI, 0, 0]} 默认锥：尖在 +Y、大口在 −Y（口朝下）。再绕 X 转 180° 后，大口朝上对着天花。
灯泡 球在局部 y = -0.06 在翻转后的锥尖下方，在罩外面，不是腔内。
罩材质 不透明 MeshStandardMaterial + emissive 罩自己发光，不是半透明网膜滤光。
SpotLight 局部 y = -0.1，瞄准地面，angle=0.95 引擎锥光，不读灯罩网格。开口朝哪与光锥无关。
PointLight 局部 y = -0.08，distance=12，无阴影 各向同性，天花、上门墙、地板一起照。罩挡不住它。

图 2 · 浏览器里看到天花一圈暖斑、灯罩像白漏斗朝上，就是这个朝向。

Blender 第一期白模 corridor_phase1.blend 里锥罩同样是口朝上的占位，前端是按它抄的，两边都要改。

3. 物理交互问题（根因）

#问题物理上错在哪画面后果
P1 朝向反了 真实灯罩大口是出光口，应朝地板。现在大口朝天花，密封面变成朝下的尖。 天花最亮；从下往上看是漏斗内侧，不是封闭顶。
P2 灯泡在罩外 灯丝应在腔体里，光线先碰到罩内壁再出去。球在罩下，等于裸灯泡 + 旁边一个空锥。 灯珠直接暴露；罩不定义光的形状。
P3 罩不参与光照 真实半透明网膜会衰减侧向光。WebGL 的 Point/Spot 默认不把透明网格当滤光片。灯是数学锥/球，网格只是给眼睛看的。 墙上半不该亮的地方仍被 PointLight 照到；没有「透过罩慢慢变暗」。
P4 罩在发光 emissive 把罩当成光源，等于又加了一盏灯，还朝四面八方（含天花）。 罩体过亮；进一步冲掉上下明暗。
P5 点光无遮挡 PointLight 各向同性且当前 castShadow=false。密封顶挡不住向上的能量。 上门墙、天花、远处体积都被填亮。

Three.js 不是 Cycles：没有「光子打到半透明羊皮再透射」。要模拟网膜，必须靠：开口内的窄 Spot（直射）+ 罩网格投射阴影（挡住上天花的光）+ 很弱的透射/自发光（侧向漏光）。不能指望一盏 PointLight 自动被罩滤掉。

4. 阴影问题

#现状为何不够
S1 只有 z ≤ 3.25 的 Spot 开了 castShadow（约前两盏）。 后面灯塘没有阴影；凹板、门套、人走过去时更远的灯不投影。
S2 PointLight 全部不投影。 向上、向侧的光是「穿墙」的，罩顶密封在阴影上等于不存在。
S3 灯罩 mesh 未作为遮光体设计（还可能 emissive 抵消暗部）。 即使开阴影，开口朝上时罩投下的影也在错的方向（挡地板、放天花）。
S4 Shadow map：512、bias -0.012；墙裙/凹板 raycast 已关掉但不影响阴影。 半透明网膜的彩色透射影 shadow map 做不到。最多：不透明罩挡住上天花的光 + Spot 只照开口立体角。
S5 Canvas 开了 shadows，但地板亮斑主要来自 Spot 衰减，不是罩的投影轮廓。 灯塘边缘是 penumbra 圆，不是「圆罩开口」的真实形状。

正确阴影链应是：腔内光源 → 罩顶/侧壁投下阴影到天花（天花黑）→ 开口不遮挡 → 地板/墙裙收到直射 → 侧壁半透明部分只漏很弱的光，不靠第二盏全向点光。

5. 修复方向（2026-09-08 前端已按此改过一轮）

  • 去掉灯罩的 rotation={[Math.PI,0,0]}，让 Cone 默认大口朝 −Y（地板）。顶部加盖或用封闭壳体，不要开口朝天花。
  • 灯泡球移到锥腔内（局部 y 在罩顶与开口之间）。
  • 主光：仅开口方向的 Spot（或 IES），角度对准地板 + 墙裙，不要打到天花。
  • 删掉或大幅减弱无阴影 PointLight；侧向亮暗交给半透明罩 + 极弱 emissive（强度远小于现在的 0.55 / 2.2）。
  • 罩：transparent / 低 transmission 或双面半透明；castShadow 打开，让密封顶挡住向上的光。
  • 阴影：至少近处 2～4 盏 Spot 投影；罩必须在 shadow caster 里。
  • 资产最终应是 ceiling_pendant.glb（口朝下、顶封闭），前端只实例化，不再用翻转的 coneGeometry 占位。

2026-09-08：朝向、腔内灯泡、朝下 Spot、去掉房间级点光，已在 CeilingLights.jsx 落地。气质改为 scheme-A 深色浅盘罩（不是半透明羊皮）。天花改为暗色微亮哑光，地板保留反光。未决：删罩外侧楞条；正式 GLB。见 现网进度.html。
